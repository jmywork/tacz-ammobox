# 自动化链路

本模组把「散装弹药 → 盒 → 箱 → 弹药盒 → 哨戒动力臂」串成一条产线。下面每条链路都可以只用原版漏斗，也可以接 Create / Pipez / RS / AE2。

## 1. 基础包装链

```text
散装弹药（TACZ）
   │  打包机（打包模式，60 发/盒）
   ▼
弹药盒 ──9 盒/箱──▶ 弹药箱
   │                    │
   │  打包机（拆包）      │  部署器 / 装填机
   ▼                    ▼
散装弹药            TACZ 本体弹药盒
```

- 打包机两槽：输入只进不出，输出只出不进；
- 过滤槽是标记槽，放什么弹种就只处理什么，不消耗物品；
- 自带漏斗默认开启，没有管道也能「箱子 → 打包机 → 装填机 → 箱子」串起来。

## 2. 装填链（生产满弹药盒）

```text
空弹药盒 ─┐
          ├─▶ 装填机（三槽）─▶ 满弹药盒 ─▶ 机械手/管道 ─▶ 哨戒动力臂
盒 / 箱 / 散弹 ─┘
```

- 装填机按 60 发为最小单位转移，箱一次最多 540 发；
- 弹药盒装满，或弹药耗尽但盒未满，都会移到输出槽，避免卡住半满盒；
- 输出槽被占用且物品不同 → 停机，不吞材料。

## 3. 自动供弹弹链

```text
玩家背包 / Curios
   └─ 弹链（NBT 缓存余弹）
        │  主手枪弹匣未满时自动补
        ▼
      TACZ 枪
```

- 消耗顺序：我们的盒/箱 → TACZ 原生弹药盒 → 散装弹药；
- 整件消耗，余弹进弹链 NBT，避免半盒浪费；
- `settings.json` 的 `beltMaxStore` 可限制弹链最多缓存多少发（0 = 不限）。

## 3.5 供弹弹链（换弹时直接吃盒/箱）

```text
背包 / Curios / 精妙背包
   ├─ 我们的盒/箱 ─┐
   ├─ TACZ 弹药盒 ─┼─▶ 供弹弹链（NBT 储备）─▶ 换弹时补满弹匣
   └─ 散装弹药 ────┘
```

- 换弹动作、冷却与动画保持原版，没有“无需换弹”效果；
- 背包里没有任何弹药盒时，普通枪无法换弹，但装备弹链后可以；
- 余弹存在弹链 NBT，换弹多次后不会浪费；
- 精妙背包只取一层，嵌套背包不递归。

## 4. 自动击发弹匣（拉栓枪全自动）

```text
改枪界面
   └─ 扩展弹匣槽 ──▶ 自动击发扩容弹匣 I / II / III
                        │
                        ▼
                  拉栓枪（manual_action）
                  按下扳机 = 按档位射速连发
```

- 三档由 `config/taczammobox/autofire.json` 配置，彩蛋单档默认 300/1000，标准三档默认 10/200、20/400、30/600；
- 只对拉栓枪生效，其它枪装上也只当普通扩容弹匣；
- 打空后停火，正常换弹；弹匣没弹时不会凭空开火。

## 5. 哨戒动力臂

```text
装填机 ─▶ 满弹匣 ─▶ 机械手 ─▶ 哨戒臂（弹匣槽）
哨戒臂打空 ─▶ 空弹匣 ─▶ 人工或机械手回收
```

- 哨戒臂能用带自动击发弹匣的拉栓枪连续开火，但射速是它自身的拉栓节奏，不是玩家那种全自动；
- 弹匣消耗与玩家一致，不会白送子弹。

## 6. 推荐的三种起步产线

| 规模 | 链路 |
|---|---|
| 手动 | 打包机 → 装填机 → 手动把满盒塞进哨戒臂 |
| 半自动 | 箱子 → 打包机 → 装填机 → 箱子 → 机械手塞哨戒臂 |
| 全自动 | 弹药产出 → 打包机 → 装填机 → 机械手 → 哨戒臂，空盒回流 |
