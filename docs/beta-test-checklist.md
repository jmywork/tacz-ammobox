# 发布检查清单

> 本文按版本累积。0.3.0 段是基线回归项，0.4.0 段是在其之上的新增验收项；发版时两段都要过。

## 0.4.0 新增验收（稳定性与配置）

### 配置文件

- [ ] 启动后生成 `config/taczammobox/features.json`，含中英注释与示例
- [ ] 启动后生成 `config/taczammobox/autofire.json`，四档（第一条彩蛋 300/1200，后三条标准 10/200、20/400、30/600）
- [ ] `settings.json` 出现 `beltMaxStore` 字段（默认 0）
- [ ] 启动日志出现 `[taczammobox] features: ...` 与 `auto-fire tiers: ...`
- [ ] 启动日志出现 `TACZ compatibility check passed`

### 特性开关

- [ ] `/taczammobox doctor` 末尾输出 `features:` 与 `guards:`
- [ ] `rpmOverride: false` + reload 后，三级弹匣射速回到枪械原版
- [ ] `capacityOverride: false` + reload 后，弹容回到枪械原版
- [ ] `belt: false` + reload 后，弹链不再自动补弹
- [ ] `createCompat: false` + reload 后，部署器不再识别盒/箱
- [ ] `safeMode: true` + reload 后，无拉栓跳过、无射速/弹容覆盖，物品与机器仍可用
- [ ] `easterEggTab: false` + reload 后重开创造栏，弹链与三级弹匣不再出现

### 弹匣参数

- [ ] 改 `autofire.json` 的 `rpm` 后 `/taczammobox reload`，射速变化
- [ ] 改 `capacity` 后 reload，HUD 弹容变化
- [ ] `rpm` 超过 1200 被钳制到 1200
- [ ] `capacity` 为 0 或负数被钳制到 1

### 弹链储备

- [ ] `beltMaxStore: 120` 时，弹链储备停在 120 不再增长
- [ ] `beltMaxStore: 0` 时不限制

### 双端同步

- [ ] 服务端改 `features.json` 并 reload，已连接客户端行为同步变化
- [ ] 客户端本地 `features.json` 与服务端不一致时，以服务端为准
- [ ] 客户端/服务端 jar 版本不一致时连接被拒绝（协议版本 6）

### JEI 与文档

- [ ] JEI 中出现「自动击发弹匣」分类，三级各一条
- [ ] 分类里显示适用枪型（实际加载的拉栓枪）与弹容/射速
- [ ] 关闭 `autoFire` 后 JEI 分类不再出现
- [ ] README 的三条文档链接可打开，代码块渲染正常

### 供弹弹链

- [ ] 生存模式下能合成（3×3 配方：铁锭 + 皮革 + 箱子）
- [ ] 背包里没有任何弹药盒时，装备弹链后按 R 能开始换弹
- [ ] 换弹结束后弹匣被补满，弹链储备相应减少
- [ ] 只有散装弹药时也能换弹，散装按发数消耗
- [ ] 只有 TACZ 原生弹药盒时也能换弹
- [ ] 弹链储备打空且背包无弹药时，换弹不再补弹
- [ ] 精妙背包里的弹药能被消耗，嵌套背包里的不会
- [ ] 不装弹链且无弹药盒时，换弹仍被拒绝（原版行为）

### 弹药装配机

- [ ] GUI 分三列，列间有分隔线，标题与列名不重叠
- [ ] 第一列列出所有可生产弹药，点选后第二列刷新
- [ ] 第二列每条配方显示完整材料图标与数量，数字不压图标、不互相重叠

- [ ] 箱子放在「入」面，机器自动取料，且只取所需数量
- [ ] 材料不足时停机，补料后继续
- [ ] 产物从「出」面进入相邻容器
- [ ] 六面按钮循环「入/出/禁用」，红石模式生效

### 标准自动击发弹匣

- [ ] 枪械工作台：狙击扩容弹匣 III + 下界合金锭 ×4 + 下界之星 ×4 → 标准 I

### TACZ 1.2.0 适配回归

- [ ] 盒/箱能往 TACZ 1.2.0 的弹药库（铁/金/钻石三级）填充弹药

- [ ] 弹链、三级弹匣、浮游炮在物品说明末尾标注「彩蛋物品」

### 浮游炮（卫星枪）

- [ ] 机架最多装 10 把枪；拆下重装不丢枪，换维度后仍在
- [ ] 待机时在身后排成枪口朝天的天使翅膀，贴背且不穿模

## 0.3.0 基线回归

> 0.3.0 包含原计划单独发布的 0.2.1 盒堆（已合并）与自动供弹弹链。

## 环境

- Minecraft 1.20.1
- Forge 47.3.19（或 47.4.x）
- TACZ 1.1.8-hotfix2
- Create 6.0.8 可选：仅部署器兼容需要
- 第三方枪包可选

## 安装

1. 把 `taczammobox-1.20.1-0.3.0.jar` 放进 `mods/`
2. 安装 TACZ 和枪包
3. 启动一次，确认生成：
   - `config/taczammobox/ammo_boxes.json`
   - `config/taczammobox/settings.json`
4. 如果装了第三方枪包：
   - 执行 `/taczammobox scan`
   - 重启客户端/服务端
   - 把生成的 `ammo_boxes.json` 同步给所有玩家
