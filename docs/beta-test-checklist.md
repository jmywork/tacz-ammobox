# 0.1.0-beta 内测检查清单

## 环境

- Minecraft 1.20.1
- Forge 47.3.19（或 47.4.x）
- TACZ 1.1.8-hotfix2
- Create 6.0.8 可选：仅部署器兼容需要
- 第三方枪包可选

## 安装

1. 把 `taczammobox-1.20.1-0.1.0-beta.jar` 放进 `mods/`
2. 安装 TACZ 和枪包
3. 启动一次，确认生成：
   - `config/taczammobox/ammo_boxes.json`
   - `config/taczammobox/settings.json`
4. 如果装了第三方枪包：
   - 执行 `/taczammobox scan`
   - 重启客户端/服务端
   - 把生成的 `ammo_boxes.json` 同步给所有玩家
